Shown as Submitted on Canvas, never just “Submitted”. Canvas is the only source — work handed in through Gradescope, Ed or anywhere else is invisible here and will still read as unsubmitted.

Removes the cached snapshot and the “new since you last looked” history. Does not sign you out of Canvas.

Direction in one line

Near-monochrome, rules instead of cards, colour only where it carries meaning. Closer to a well-set document than a dashboard.

Type

13px base, 1.5 line-height, system stack (Segoe UI Variable on Windows reads close to Inter and ships nothing). Headings 600 weight with -0.011em tracking. Every time and count uses font-variant-numeric: tabular-nums so columns align — in a due-date list that is not cosmetic.

Colour

Seven neutrals do the work. One accent (indigo) marks interaction and selection only — never decoration. Three semantic colours mean exactly one thing each: red overdue/missing, amber due soon, green submitted. Because they are rare, they read instantly.

Courses are identified by a 7px dot, not a coloured row. Four coloured bands stacked would fight the calm; four dots read as a key.

Deliberately not Cornell carnelian as the accent: it is within a few degrees of the overdue red, and an interface where “your brand” and “you are late” look alike is a bad interface.

Density

8px spacing grid. List rows 36px, tree rows 28px, side-panel rows 32px. Dividers are 1px hairlines, and groups are separated by space rather than boxes — the Today list has no card in it at all.

Light & dark

Both first-class, driven by tokens on :root. Dark is its own ramp, not an inversion: near-black #0d0d10 with a cool cast, and semantic colours re-picked for contrast on it rather than reused.

Two things the mock is arguing for

“Submitted on Canvas”, never “Submitted”. The longer label is load-bearing. Anything handed in through Gradescope or Ed is invisible to this extension and will read as unsubmitted, and a bare “Submitted” implies a completeness the data does not have.

The download path is shown, not hidden. Files land in a folder the user did not choose, so the destination appears in the progress panel and in Settings rather than being discoverable only afterwards.
